# ESP32-S3 四传感器杜邦线测试接线

本套接法用于 PCB 到货前测试，兼容已经烧录的 `carrier-network-1.0.1` / `carrier-network-1.0.2` 程序。无需重新烧录。接线图中的行顺序表示连接关系，并不表示传感器排针的实际左右顺序；务必按实物引脚丝印接线。

## 1. 电源与分线

准备一个**稳压 5V 电源，推荐 2A**。本图按同一个电源同时供应全部模块设计：

```text
同一个稳压 5V 电源
  正极 ─┬─ ESP32 排针上的 5V（输入）
        ├─ LD2410C VCC
        └─ MQ VCC
  负极 ─── 全部 GND 共地

ESP32 的 3V3 输出 ─┬─ GY-302 VCC
                   ├─ BME688 VCC / CS
                   └─ MQ 保护电路的 GPIO5 上拉电阻
```

**采用以上供电时，ESP32 的两个 USB 都拔掉。** 不要再叠加电脑 USB 或第二个独立 5V 电源。ESP32 已保存 Wi-Fi 配置，上电后可直接通过 Wi-Fi 连接网站，不需要电脑 USB。

5V 正极应先在端子或电源分线处分成三路，不让 MQ 加热器和雷达的电流先经过 ESP32 开发板。电源线保持短，接头要牢固；不要使用未稳压的电源或超过 5.25V 的电压。

GPIO8、GPIO9、3V3、GND 都需要分叉，可用小面包板、分线端子或可靠的一分多接线。部分面包板电源轨中间断开，需要用万用表检查或补桥。信号线尽量控制在约 20cm 内。

若暂无 MQ 保护器件，先省略 MQ 的全部连接，使用同一电源测试另外三个传感器。

## 2. 四个模块的连接表

所有 GND 都接电源负极和 ESP32 GND。这里的 GPIO 编号指 ESP32 排针丝印的数字，不是排针第几脚。

| 模块 | 模块引脚 | 接到 |
|---|---|---|
| GY-302 / BH1750 | VCC | ESP32 3V3 |
| GY-302 / BH1750 | GND | GND |
| GY-302 / BH1750 | SCL | GPIO9 |
| GY-302 / BH1750 | SDA | GPIO8 |
| GY-302 / BH1750 | ADDR | GND，地址 0x23 |
| BME688 | VCC | ESP32 3V3 |
| BME688 | GND | GND |
| BME688 | SCL | GPIO9 |
| BME688 | SDA | GPIO8 |
| BME688 | SDO | GND，地址 0x76 |
| BME688 | CS | ESP32 3V3，选择 I2C 模式 |
| LD2410C | VCC | 同源 5V 正极 |
| LD2410C | GND | GND |
| LD2410C | TX | GPIO17，ESP32 接收 |
| LD2410C | RX | GPIO18，ESP32 发送 |
| LD2410C | OUT | GPIO16 |
| MQ | VCC | 同源 5V 正极 |
| MQ | GND | GND |
| MQ | AO | 第 3 节分压电路，再到 GPIO4 |
| MQ | DO | 第 4 节三极管电路，再到 GPIO5 |

GY-302 和 BME688 共用一条 I2C 总线。模块已有上拉电阻时，不需要再加上拉电阻。LD2410C 的 TX 接 ESP32 的 RX，RX 接 ESP32 的 TX，不是 TX 接 TX；厂家规定其供电为 5V、IO 为 3.3V，固件使用 UART 256000 baud / 8N1。

你提供的 ESP32 照片中，金属屏蔽罩正面朝自己、天线在上、两个 USB 在下时，本次使用的 GPIO 都在左排：`4、5、16、17、18、8、9`。5V 在左排倒数第二脚，GND 在最后一脚；3V3 在左排顶部。仍以实物丝印为准，不按照片颜色或插头方向猜脚。

## 3. MQ AO 分压：A 点接 GPIO4

```text
MQ AO ── 6.8kΩ（1%）──┬── A 点 ── GPIO4
                       ├── 7.5kΩ（1%）── GND
                       ├── 100kΩ ──────── GND
                       └── 100nF ──────── GND
```

7.5k、100k 和 100nF 三个支路并联到 GND。100nF 可以使用无极性的陶瓷电容，常见标识为 `104`。

这里采用与已烧录程序一致的 6.8k / 7.5k / 100k 网络，不是最初提案中的 4.7k / 7.5k。等效下臂为 7.5k∥100k，GPIO 电压为 MQ AO 的约 0.5064 倍：AO=5.00V 时 A≈2.532V；电源 5.25V 且电阻按 1% 最坏误差组合时 A≈2.685V。固件已按对应比例还原 MQ AO 电压。

**MQ AO 不得直接接 GPIO4。** 实际通电前，先不连接 GPIO4，暂用同源 5V 正极接分压网络输入，万用表测 A 点相对 GND 应约 2.53V。断电后撤掉模拟 5V 线，再把输入换成 MQ AO，最后连接 GPIO4。

## 4. MQ DO 保护：D 点接 GPIO5

使用一只直插 **NPN 2N3904**，连接如下：

```text
同源 5V ── 10kΩ ──┐
                   ├── MQ DO ── 10kΩ ── 2N3904 B（基极）
                   │
                   └── 上述节点均为 MQ 原始 DO

ESP32 3V3 ── 10kΩ ──┬── D 点 ── GPIO5
                     └── 2N3904 C（集电极）

GND ──────────────────── 2N3904 E（发射极）
```

总共三颗 10k 电阻：MQ DO 到 5V 的上拉、DO 到 B 的串联电阻、C/D 到 3V3 的上拉。C/D 节点只用 3V3 上拉，不能接 5V。

多数 LM393 MQ 模块检测到气体时原始 DO 为低；经上述反相电路后 GPIO5 为高，保持现有固件和网页默认的 `HIGH` 报警极性。你实际 MQ 模块的触发极性仍需实测后确认，若不同应在网页改报警极性。

onsemi 的 2N3904 数据手册规定引脚编号为 1=E、2=B、3=C。实际封装查看方向和厂商必须核对；不要把所有 TO-92 三极管都当成相同脚位，也不要随意换成 PNP 三极管。2N3904 是本临时接法的直插器件，作用与载板的 DO 反相保护相同。

## 6. 上电测试顺序

1. 关闭所有电源，检查 5V / 3V3 / GND 是否接反，检查 5V 与 3V3 有没有短接；两个 USB 均保持断开。
2. 先只连接 ESP32 和 GY-302，上电后打开网站，点“立即采样”，检查照度是否有新读数。感光面不要遮挡。
3. 断电，加 BME688，重新上电，检查温度、湿度、气压和气体电阻。BME688 远离 MQ 热探头，保持通风。气体电阻不等于已校准的 VOC 浓度。
4. 断电，加 LD2410C，重新上电，让雷达正面朝检测区，检查网站的人体存在状态和 UART 数据。
5. 搭好 MQ 保护网络，先测分压，再断电加入 MQ。通电后测 GPIO4/A 点和 GPIO5/D 点；确认没有超过 3.3V，完成加热预热后再在网页启用 MQ 告警和配置阈值。
6. 最后验证网页“立即采样”和默认每 5 分钟上传。现有程序会在上电后自动连接保存的 Wi-Fi 并重连 WebSocket。

每次接线或插拔都先断电。程序在启动时检测 I2C 模块，因此后来接入传感器后需要重新上电。MQ 型号尚未确认，预热与首次老化时间应按实际型号手册设置，不能把未校准 ADC 数值当作 ppm。

## 7. 数据来源与检查范围

- 实际 GPIO 与 ADC 网络：本仓库程序 `firmware/src/main.cpp`，目前版本 `carrier-network-1.0.2`；已自动核对七个 GPIO 和三个 ADC 电阻值。
- 开发板引脚位置：用户提供的 44Pin、双 Type-C、CH343 ESP32-S3 照片。

- [onsemi 2N3904 官方数据手册](https://www.onsemi.com/pdf/datasheet/2n3904-d.pdf)：NPN 类型及引脚编号。
- [Bosch BME688 官方数据手册](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme688-ds000.pdf)：I2C 模式和地址选择。
