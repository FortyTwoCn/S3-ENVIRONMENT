# 实现说明与审查

PHP-FPM（Windows 为内置 HTTP 服务）处理密码、历史 API、配置与命令入队；一个常驻 PHP Ratchet/React 进程维护设备 / 浏览器 WebSocket；独立 PHP worker 处理 SMTP、重试与过期记录。三者使用 PostgreSQL，避免将长连接生命周期绑在网页请求上。

命令由 HTTP 写入 commands 表，再由 WebSocket 进程每秒派发。MQ 事件与邮件入队放在样本保存的同一数据库事务中；邮件独立发送。PostgreSQL 临时断开后会重建连接，未 ACK 的设备样本由固件重传，唯一键阻止重复存储。

认证采用一位网站管理员 / 多设备模型。密码使用 PHP password_hash/verify，设备令牌与记住登录令牌在库中保存 SHA256 摘要，随机密钥具有 256 位熵。浏览器票据短期且一次性，检查 Origin，写接口检查 CSRF，输出使用 textContent / HTML 转义和 CSP。WebSocket 缓冲层限制 8KiB，未鉴权超时和应用消息限速。SMTP 授权码采用 sodium secretbox，APP_KEY 不存入数据库。

图表实现遵循 data-visualization 路由与 dashboards 技能：监测任务是按时间查看变化，主视图展示当前值 / 在线状态，其次为可切换指标的单张折线图；表格提供全部记录和 CSV 替代查看。页面只同时绘制一张 Chart.js Canvas，最多约 1200 个时间桶，较大时间段返回平均、最小、最大与数量，避免一次拉取 60 天全部点。缺失为 null，较长采样间隙断线；时区按浏览器本地显示，数据库使用 UTC。Boolean 指标聚合后 0–1 均值代表该桶内触发样本占比。

筛选保存在 URL，分页为每页 50 条。手机先看到设备 / 当前值，再看到趋势，表格在自身容器内横向滚动，不扩展整页宽度。图表值有表格替代，颜色不是告警 / 在线状态的唯一标识。断线保留最后数据并显示状态；表单编辑期间后台刷新不会覆盖未保存的输入。

固件固定现有 GPIO 与 ADC 分压，3.3V 逻辑 / 5V 保护仍由 PCB 硬件承担。读取缺失模块时上传 null；雷达 UART 不活跃时不假装 OUT 有效。MQ 无供电检测，因此由安装者确认后启用策略；数字极性允许修改，但默认匹配载板 Q1 反相。即时采样执行新读取，不直接返回旧缓存。

MQ 预热 / 防抖在固件执行，服务器按已启用与已就绪字段生成事件，加入时间检查、防重复事件、恢复后重新触发和冷却。离线积压按真实采样时间保存；旧读数不会推翻新的烟雾状态或触发当前邮件。当前内存缓冲有容量、断电清空；未实现 SD 卡或 Flash 持久离线队列，以减少附加器件和 Flash 写入。

已做本机浏览器、协议、数据库、SMTP 接收器、HTTPS/WSS 代理和 Windows 运行测试。固件只做实际工具链编译与代码审查，不能代替实物 Wi-Fi / PSRAM、传感器 / ADC、MQ 阈值、射频与上电验证；实际邮件服务和公网 ACME 申请也须部署后验证。当前 Docker 文件经过 Compose/Caddy 配置校验，未在此电脑上运行容器。
